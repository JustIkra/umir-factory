# reference/durable

Эталонный Go-модуль durable-стека (PostgreSQL, RabbitMQ, Redis): пакеты `postgres`, `rabbitmq`, `redis`, `relay` и тестовая инфраструктура `itest`. Сервисы копируют пакеты в свои `internal/adapters/*`, а не импортируют их. Это каркас: полный README (пакеты, функции, тесты, правила копирования) пишет задача T7. Файл `deps.go` в корне модуля временный: он закрепляет зависимости, пока пакеты пишутся параллельно, и удаляется ведущим в финале вместе с итоговым `go mod tidy`.
