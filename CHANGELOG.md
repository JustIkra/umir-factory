# Изменения

## Не выпущено

- Проверки check-images и smoke перенесены на автономный Go CLI; заменённые Python-скрипты удалены.
- Добавлены реальный bridge и совместные бизнес-тесты двух Runtime, локальный runner и проверка фиксированных commit через временный workspace.
- Добавлены проверки опубликованных портов, env-file и явных URL для smoke.
- Сохранены проверки существования commit, успешной публикации и OCI metadata/HEALTHCHECK; dev-сборка использует отдельные локальные теги.
- Добавлены закреплённые gates для обоих вложенных Go-модулей и opt-in business job для реализованных выбранных SHA.
- Обновлены архитектура и описание фактических публичных границ; выбранные production-образы остаются прежними.
- Bridge теперь явно переводит `DishDetails`, сохраняя `EvaluatedAt`/`StateVersion` и копируя вложенный `Dish`; совместный тест проверяет метаданные и изоляцию рецепта.
- Архитектура описывает повтор ошибок snapshot Save по настроенному интервалу без остановки HTTP или обработки истечения.

## [0.1.0] - 2026-10-10

- Добавлены сборка четырёх сервисов по SHA образов и локальная сборка.
- Добавлена проверка конфигурации Compose в CI.
